PIPE

Status pipeline

Each stage watches for batches whose StatusText matches its input status, and writes the output status/code back once a batch finishes. Crop's input defaults to matching Rotation's output so batches flow through automatically -- edit them independently if your workflow differs.

Auto-Crop automation

Automation only works while a database connection has been made this session (Database source, either tab) -- folder mode has no status column to poll, so it stays manual. The scheduler checks every 20s in the background; a stage already mid-run is skipped until it finishes.

MODEL

Orientation models

One or more trained checkpoints. A batch's DocumentType (read from batchtable when that column exists) is matched against each profile's match text (case-insensitive, substring). Leave match blank for the catch-all default profile. Multiple checkpoints for one profile (comma-separated paths) are ensembled together, same as the original script.

OLLAMA

Ollama fallback for uncertain pages

When enabled, pages the classifier isn't confident about (or every page, depending on trigger) are also shown to a local Ollama vision model, and its answer is used for the rotation instead.
